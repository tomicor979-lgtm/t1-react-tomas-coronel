# T1 — Portfolio de Tomas Coronel

Portfolio personal de una sola página. Presenta a Tomas Coronel, sus intereses en desarrollo web, herramientas que está aprendiendo y proyectos de práctica.

## Tecnologías

- React y JSX
- Vite
- JavaScript
- CSS responsive
- Lucide React para iconos

El proyecto se inició con `npm create vite@latest` usando la plantilla React.

## Referencia visual

La estructura general de portfolio personal toma como referencia **Cleanfolio**, una plantilla React publicada bajo licencia MIT: https://github.com/rjshkhr/cleanfolio. Se adaptaron sus ideas de presentación personal, habilidades y proyectos al contenido de Tomas Coronel y a los requisitos de este trabajo; los componentes y estilos de esta entrega están implementados para este proyecto.

## Instalación y ejecución

Necesitás Node.js instalado. Desde esta carpeta, ejecutá:

```bash
npm install
npm run dev
```

Abrí en el navegador la dirección local que muestra Vite (normalmente `http://localhost:5173`). Para generar una versión de producción:

```bash
npm run build
npm run preview
```

## Contenidos del trabajo

- Componentes reutilizables para encabezado, presentación, perfil, habilidades, proyectos y pie de página.
- Props para compartir los datos del perfil y mostrar habilidades y proyectos.
- Arrays, `map()` y `key` para generar listas.
- `useState`, evento `onClick` y renderizado condicional en el bloque “Un poco más sobre mí”.
