# Mi portfolio — Tomas Coronel

Este es mi portfolio personal, hecho para el trabajo práctico de React. Presenta un poco sobre mí, las tecnologías que estoy aprendiendo y dos proyectos de práctica.

Lo inicié con `npm create vite@latest` y la plantilla de React. Está hecho con React, JavaScript, JSX y CSS. Para los iconos usé Lucide React. Como referencia para organizar las secciones miré [Cleanfolio](https://github.com/rjshkhr/cleanfolio); después adapté el contenido y los estilos para este trabajo.

Para verlo en tu computadora, necesitás tener Node.js instalado. Cloná este repositorio, abrí una terminal en la carpeta del proyecto y ejecutá:

```bash
npm install
npm run dev
```

Vite te va a mostrar una dirección local para abrir en el navegador. El sitio publicado está en [GitHub Pages](https://tomicor979-lgtm.github.io/t1-react-tomas-coronel/) y el código, en este [repositorio](https://github.com/tomicor979-lgtm/t1-react-tomas-coronel).
